새 소식

Dawnbringer의 모든 업데이트와 변경 내용.

Dawnbringer 0.5.0

2026년 10월 21일 · Android · Windows · macOS · Linux

  • 레벨마다 능력치 포인트 5와, 3갈래 스킬 트리용 스킬 포인트 1을 얻는다
  • 2차 직업 12종: 지주를 쓰러뜨리면 직업 교관이 전직이나 진영 변경을 허락한다
  • 이제 모든 캐릭터가 말한다: 전설, 지도의 NPC, 19종의 몬스터
  • 부위별 장비: 무기, 방패, 머리, 몸통, 망토, 부츠, 부적 3개
  • 대장간에서 장비를 +4까지 재가열하고 몬스터 카드를 장착한다
  • 속도가 각 전사의 행동 횟수를 정하고, 일어선 자들이 밤낮으로 너를 쫓는다

Dawnbringer 0.4.0

2026년 10월 18일 · Windows · macOS · Linux

  • 정확한 예측은 이제 없다: 적의 아이템을 확인하면, 죽음이 기다리는 싸움 앞에서 절망의 돌이 어두워진다
  • 상징적인 적 19종: 각자 수법의 바탕이 되는 아이템을 지녔다
  • 퀘스트가 있고 각자의 음악을 지녔으며, 만날 때마다 대사가 바뀌는 NPC 10명
  • 주검과 베일 계열, 새 아이템 32종, 새 이벤트 19종
  • 건너뛸 수 있는 짧은 튜토리얼
  • 모든 영웅에게 이름이 주어지며, 이름을 바꿀 수 있다
  • 휴대폰과 대형 화면에서 더 선명한 그래픽
  • 모든 화면에 버그 버튼

Dawnbringer 0.3.0

2026년 10월 17일 · Windows · macOS · Linux

  • 새로운 아이템 계열 2종: 주검은 전투에서 이길 때마다 성장하고, 베일은 영웅에게 희미함을 준다
  • 새 아이템 32종: 상점의 장비와 빌드가 더 다양해졌다
  • 새 이벤트 19종과 새로운 적 계열 2종으로 런의 반복이 줄었다
  • 모든 화면에 버그 버튼: 캡처, 표시, 신고 보내기
  • 웹사이트에서 PC 데모 제공

Dawnbringer 0.2.0

2026년 10월 16일 · Android

  • 이야기: 마지막 야영의 헤스퍼 어머니, 목소리가 입혀진 지주와 영웅, 묘비명과 파편
  • 지주의 밤: 피의 달, 새로운 음악, 지주가 가는 길에서 마주친 것을 죽인다
  • 난이도 재조정; 전설은 2주 차부터만 등장
  • UI: 키릴 문자와 CJK 폰트, 툴팁, 예보 색상
  • 개인정보 처리방침
