업데이트 기록

Dawnbringer의 모든 업데이트와 버전별 변경 사항.

Dawnbringer 0.8.0

2026년 11월 19일 · Android · Android 데모 · Windows 데모 · macOS 데모 · Linux 데모

  • 사냥꾼, 몬스터, 지주, 장착 장비에 SVG 벡터 아트 적용. 0.8.0에서 전투 배경, 지도 타일, UI는 아직 픽셀 아트입니다
  • 서버 재실행으로 검증하는 주간 도전과 도시·지역·국가별 온라인 순위표. 도시, 국가만, 또는 공개 순위표에 올리지 않는 위치 없음 중 선택하며 다른 플레이어의 사냥꾼을 소굴 맞수로 만납니다
  • 사냥꾼 코드로 친구와 싸우거나 한 기기에서 저장된 사냥꾼 둘을 맞붙이는 오프라인 결투
  • 스킬 트리에 액티브 스킬 8개와 규칙을 바꾸는 노드 18개, 그리고 장비 부위별 전문 상점 추가
  • 선택한 성별에 맞춘 사냥꾼 음성, 해설자 여백, 브라질 포르투갈어 전체 더빙 지원
  • 색각 이상 팔레트, 도형 표식, Android 기기 내 음성 조작, 실시간 옵션 도표 및 휴대폰, 태블릿, PC 전체 화면 지원
  • Google Play 비공개 테스트에 별도의 무료 Android 데모 앱 추가

Dawnbringer 0.7.2

2026년 11월 7일 · Android · Windows 데모 · macOS 데모 · Linux 데모

  • 런마다 사냥꾼을 직접 만드세요: 몸, 머리, 옷, 무기
  • 은행 돈으로 집의 방을 여세요: 스승, 장인, 더 큰 지갑 중 하나가 생깁니다
  • 직업은 두 단계로, 처음 두 지주를 쓰러뜨릴 때마다 열립니다
  • 스킬 트리는 확대와 드래그가 되는 하나의 지도입니다
  • 길드 네 곳: 등급, 런마다 계약, 대립하는 한 쌍
  • 문에 지역, 적, 그 지역이 선호하는 아이템이 표시됩니다
  • 적마다 공격 방식이 다릅니다: 짓밟기, 돌진, 투척, 침 뱉기

Dawnbringer 0.5.0

2026년 10월 21일 · Android · Windows 데모 · macOS 데모 · Linux 데모

  • 레벨마다 능력치 포인트 5와, 3갈래 스킬 트리용 스킬 포인트 1을 얻는다
  • 2차 직업 12종: 지주를 쓰러뜨리면 직업 교관이 전직이나 진영 변경을 허락한다
  • 이제 모든 캐릭터가 말한다: 전설, 지도의 NPC, 19종의 몬스터
  • 부위별 장비: 무기, 방패, 머리, 몸통, 망토, 부츠, 부적 3개
  • 대장간에서 장비를 +4까지 재가열하고 몬스터 카드를 장착한다
  • 속도가 각 전사의 행동 횟수를 정하고, 일어선 자들이 밤낮으로 너를 쫓는다

Dawnbringer 0.4.0

2026년 10월 18일 · Windows 데모 · macOS 데모 · Linux 데모

  • 정확한 예측은 이제 없다: 적의 아이템을 확인하면, 죽음이 기다리는 싸움 앞에서 절망의 돌이 어두워진다
  • 상징적인 적 19종: 각자 수법의 바탕이 되는 아이템을 지녔다
  • 퀘스트가 있고 각자의 음악을 지녔으며, 만날 때마다 대사가 바뀌는 NPC 10명
  • 주검과 베일 계열, 새 아이템 32종, 새 이벤트 19종
  • 건너뛸 수 있는 짧은 튜토리얼
  • 모든 영웅에게 이름이 주어지며, 이름을 바꿀 수 있다
  • 휴대폰과 대형 화면에서 더 선명한 그래픽
  • 모든 화면에 버그 버튼

Dawnbringer 0.3.0

2026년 10월 17일 · Windows 데모 · macOS 데모 · Linux 데모

  • 새로운 아이템 계열 2종: 주검은 전투에서 이길 때마다 성장하고, 베일은 영웅에게 희미함을 준다
  • 새 아이템 32종: 상점의 장비와 빌드가 더 다양해졌다
  • 새 이벤트 19종과 새로운 적 계열 2종으로 런의 반복이 줄었다
  • 모든 화면에 버그 버튼: 캡처, 표시, 신고 보내기
  • 웹사이트에서 PC 데모 제공

Dawnbringer 0.2.0

2026년 10월 16일 · Android

  • 이야기: 마지막 야영의 헤스퍼 어머니, 목소리가 입혀진 지주와 영웅, 묘비명과 파편

  • 난이도 재조정; 전설은 2주 차부터만 등장
  • UI: 키릴 문자와 CJK 폰트, 툴팁, 예보 색상
