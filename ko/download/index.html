무료 PC 데모 다운로드

Windows, macOS, Linux에서 시간 제한 없이 Dawnbringer를 무료로 즐겨 보세요. 기본 사냥꾼 구성으로 3주 전체 런을 플레이하며, 집의 영구 방 22개는 닫혀 있습니다. 버전 0.8.0.

데모 포함 내용

  • 매 런 전 성별, 피부, 눈, 머리, 복장, 이름까지 완전한 사냥꾼 꾸미기.
  • 시작 보너스 2종, 받아치기와 첫 피, 그리고 시작 무기 2종, 쇠몽둥이와 낡은 석궁.
  • 1차 직업 2종, 소드맨과 아처, 그리고 2차 직업 4종: 크루세이더, 나이트, 헌터, 바드.
  • 모든 지역을 아우르는 3주 전체 런. 도로 이벤트, 장비 부위별 전문 상점, 더 가혹한 규칙 대신 추가 골드를 얻는 선택 서원, 매주 등장하는 지주 보스 포함.
  • 2, 4, 6개 장착 시 세트 보너스를 여는 시작 아이템 계열 4종.
  • 정식 버전과 분리된 세이브 파일. 추가 보너스 4종, 무기 4종, 1차 직업 4종, 아이템 계열 6종과 더 큰 출발 골드 지갑을 여는 집의 22개 방은 정식 버전에 포함됩니다.

  • Windows

    Windows 10 또는 11, 64비트. .zip 파일을 내려받아 압축을 풀고 설치 없이 DawnbringerDemo.exe를 실행하세요. 아직 코드 서명이 없어 Windows SmartScreen이 한 번 경고할 수 있습니다. 추가 정보를 누른 뒤 실행을 클릭하세요.

    다운로드 (360.2 MB).zip

  • macOS

    Apple silicon과 Intel Mac 공용 앱입니다. 압축을 풀고 Dawnbringer를 응용 프로그램 폴더로 끌어다 놓으세요.

    Apple이 아직 앱을 공증하지 않아 macOS가 첫 실행을 차단합니다. 앱을 우클릭하거나 Control-클릭해 열기를 선택하세요. 열기가 보이지 않으면 시스템 설정 > 개인정보 보호 및 보안에서 확인 없이 열기를 누르세요.

    다운로드 (392.6 MB).zip

  • Linux

    x86_64 압축 파일입니다. 압축을 풀고 DawnbringerDemo.x86_64를 실행하세요. OpenGL 3.3 지원 그래픽 드라이버가 필요합니다.

    다운로드 (356.3 MB).tar.gz
