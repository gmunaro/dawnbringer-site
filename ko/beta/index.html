Android 알파 참여

출시 전에 Android 버전을 무료로 플레이하세요. 4단계, 약 2분이면 됩니다.

테스트 결제 금액은 가상입니다. 실제로 청구되지 않습니다.

Test card, always approves를 쓰면 Google Play는 구매를 시뮬레이션할 뿐입니다. R$9.99 등 어떤 금액이 표시되어도 돈이 빠져나가지 않습니다. 이 결제 수단이 선택되어 있는지 확인하세요. 본인 카드나 다른 실제 결제 수단이 보이면 확정하지 말고 문의해 주세요.

모든 단계에서 같은 Google 계정을 쓰세요. Android 기기의 Play 스토어에 로그인한 계정입니다. 사진은 영어로 된 Google 화면이지만, 한국어에서도 버튼은 같은 자리에 있습니다. 초록색 테두리의 버튼을 누르세요.

  1. 1 테스터 그룹 가입

    그룹을 열고 "Join group"(그룹 가입)을 클릭하세요. 창이 열리면 아래쪽의 "Join group"을 한 번 더 클릭하세요. 페이지에 "Successfully joined the group"이 표시됩니다. 그룹을 열기만 해서는 안 되고, 가입해야 합니다.

    그룹 열기

  2. 2 테스터 되기

    같은 계정으로 테스트 페이지를 열고 "Become a tester"를 클릭하세요. "You are a tester."가 표시될 때까지 기다리세요.

    테스트 페이지 열기

  3. 3 휴대폰에서 게임 열기

    Android 휴대폰이나 태블릿에서 Google Play의 게임 페이지를 여세요. 페이지 이름은 "Dawnbringer (Early Access)"입니다. 가격이 적힌 파란 버튼을 누르세요.

    Google Play에서 설치

  4. 4 테스트 카드로 확인

    Google Play가 결제 화면을 엽니다. 결제 수단이 "Test card, always approves"이고 화면에 테스트 주문이라고 나오는지 확인한 뒤 "1-tap buy"를 누르세요. 게임이 설치되고 요금은 청구되지 않습니다.

무료 알파 이용은 출시와 함께 끝납니다. 테스트 참여에 정식 버전 구매는 포함되지 않습니다.

설치에 도움이 필요한가요?

모든 단계에서 같은 계정을 쓰세요. 그룹, 테스트 페이지, Play 스토어입니다. Google 계정이 여러 개라면 각 페이지와 스토어 앱에서 프로필 사진을 확인하세요.

Test card, always approves는 무엇인가요?

Google Play의 테스트 결제 카드입니다. 결제 수단이 Test card, always approves라면 확정해도 모의 구매만 진행되어 실제로 청구되지 않습니다. 본인 카드나 다른 실제 결제 수단이 보이면 확정하지 마세요. 세 단계에서 쓴 계정을 확인하고 문제가 계속되면 문의하세요.

게임이 안 보이거나 테스트에 참여할 수 없나요?

Play 스토어 계정으로 그룹에 가입하고 테스트 참여를 수락했는지 확인하세요. 몇 분 뒤 테스트 페이지를 다시 여세요. 그래도 접근할 수 없다면 결제 정보를 제외한 안내 메시지 스크린샷을 다음 주소로 보내 주세요: dawnbringergame@gmail.com
