Android 알파 참여

출시 전에 Android 버전을 무료로 플레이해 보세요.

테스트 결제 금액은 가상입니다. 실제로 청구되지 않습니다.

Test card, always approves를 쓰면 Google Play는 구매를 시뮬레이션할 뿐입니다. R$9.99 등 어떤 금액이 표시되어도 돈이 빠져나가지 않습니다. 이 결제 수단이 선택되어 있는지 확인하세요. 본인 카드나 다른 실제 결제 수단이 보이면 확정하지 말고 문의해 주세요.

  1. 1

    Dawnbringer Testers를 열고 그룹 가입을 누릅니다. Android의 Play 스토어에서 쓰는 Google 계정으로 로그인하세요. 그룹을 여는 것만으로는 부족하니 가입을 확정하세요.

    그룹 열기

  2. 2

    같은 계정으로 테스트 페이지를 열고 테스터 되기를 누릅니다. 참여 확인이 표시된 뒤 다음 단계로 진행하세요.

    테스트 페이지 열기

  3. 3

    Android 휴대폰이나 태블릿에서 Google Play의 게임 페이지를 열고 설치를 누릅니다. 컴퓨터에서는 창에 표시된 Android 기기를 선택한 뒤 Install 또는 설치를 누릅니다.

    Google Play에서 설치

무료 알파 이용은 출시와 함께 끝납니다. 테스트 참여에 정식 버전 구매는 포함되지 않습니다.

설치에 도움이 필요한가요?

그룹, 테스트 페이지, Play 스토어에서 같은 계정을 쓰세요. Google 계정이 여러 개라면 각 페이지와 스토어 앱의 프로필 사진을 확인하세요.

가격이나 구매 버튼이 보이나요?

테스터에게도 가격이 표시될 수 있습니다. 먼저 1단계와 2단계를 마치세요. 컴퓨터에서는 Buy 또는 구매를 눌러 기기 선택 창을 여세요. 이미지처럼 Install 또는 설치가 표시되면 Android 기기를 골라 그 버튼을 누르세요. 결제 화면이 뜨면 확정하기 전에 테스트 카드 설명을 읽으세요.

Test card, always approves는 무엇인가요?

Google Play의 테스트 결제 카드입니다. 결제 수단이 Test card, always approves라면 확정해도 모의 구매만 진행되어 실제로 청구되지 않습니다. 본인 카드나 다른 실제 결제 수단이 보이면 확정하지 마세요. 세 단계에서 쓴 계정을 확인하고 문제가 계속되면 문의하세요.

게임이 안 보이거나 테스트에 참여할 수 없나요?

Play 스토어 계정으로 그룹에 가입하고 테스트 참여를 수락했는지 확인하세요. 몇 분 뒤 테스트 페이지를 다시 여세요. 그래도 접근할 수 없다면 결제 정보를 제외한 안내 메시지 스크린샷을 다음 주소로 보내 주세요: dawnbringergame@gmail.com
