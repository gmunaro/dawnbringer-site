下载免费电脑试玩版

在 Windows、macOS 或 Linux 上无时间限制免费试玩 Dawnbringer。你可以用初始猎人选项玩完整个三周出征，宅子的22个永久升级房间保持关闭。 当前版本 0.8.0。

试玩版包含内容

  • 每次出征前完整自定义猎人，包括性别、肤色、眼睛、发型、服装和姓名。
  • 2个初始加成，还击与初血，以及2件初始武器，铁棍与旧弩。
  • 2个初阶职业，剑士与弓箭手，及其4个进阶职业：十字军、骑士、猎人与诗人。
  • 涵盖全部地区的完整三周出征，包含道路事件、按装备栏位细分的专卖商店、以更严苛规则换取额外金币的可选誓愿，以及每周登场的地主首领。
  • 4个初始物品系列，穿戴2、4或6件同系列装备即可激活套装加成。
  • 独立于完整版的存档文件。解锁另外4个加成、4件武器、4个初阶职业、6个物品系列与更大初始金币钱袋的22个宅子房间属于完整版。

  • Windows

    Windows 10 或 11，64位。下载 .zip 压缩包解压后直接运行 DawnbringerDemo.exe，无需安装。由于文件尚未进行代码签名，Windows SmartScreen 可能会提示一次。点击「更多信息」，再点击「仍要运行」。

    下载 (360.2 MB).zip

  • macOS

    支持 Apple silicon 与 Intel Mac 的通用应用。解压后将 Dawnbringer 拖入「应用程序」。

    Apple 尚未对该应用进行公证，因此 macOS 会拦截首次启动。请右键或按住 Control 点击应用并选择「打开」。若未看到「打开」，请前往系统设置 > 隐私与安全性，点击「仍要打开」。

    下载 (392.6 MB).zip

  • Linux

    x86_64 压缩包。解压并运行 DawnbringerDemo.x86_64。需要支持 OpenGL 3.3 的显卡驱动。

    下载 (356.3 MB).tar.gz
