一款没有骰子的暗黑奇幻 Roguelike 自走棋。每次出征历时三周。在自动战斗前查看每个敌人的真实装备，向每周首领缴税或迎战，过关后再决定回家把钱袋存进钱庄，还是押上一切闯入更险的一周。战死会带走你身上携带的一切。

  • 下载免费试玩版Windows, macOS, Linux
  • 加入 Android 测试Google Play，测试员免费

实机画面

主视觉展示的是 0.9 计划采用的视觉风格。0.8.0 版本在像素风背景与界面之上使用矢量角色和装备，手柄支持目前为部分支持。

一次出征如何进行

  1. 1. 从钱庄押注金币出发

    太阳碎裂，发光碎片成了货币，宅子是你在出征之间的永久基地。出发前创建猎人，挑选初始加成和武器，并在钱袋上限内从安全钱庄取出金币放进钱袋。钱袋里的金币用于在途中购买装备、消耗品、铁匠铺强化和神龛祝福，带得越多前期越强，但战死时的损失也更大。战死只会失去钱袋，绝不会动到钱庄。

  2. 2. 探索三周并读懂每场战斗

    在迷雾笼罩的格子地图上度过白昼与危险黑夜。每个敌人携带的装备与属性全部可见。战斗自动结算且没有骰子，开战前你可以把对手构筑与自己逐项对比。

  3. 3. 向地主缴税或开战，再决定去留

    每周结束时，统治该地区的首领地主会前来收税。第1周和第2周你可以开战赢取赏金，或缴纳供奉，数额为钱袋的30%与该周最低额中的较高者。第3周不收供奉。撑过地主后，你决定回家把钱袋存进钱庄，还是带着全部家当进入下一周。

  4. 4. 培养猎人并解锁宅子

    第1周后学习初阶职业，第2周后学习进阶职业，在单张技能树地图上分配点数，凑齐物品系列套装并在铁匠铺强化装备。出征之间，用钱庄金币解锁宅子的22个永久房间。

独特之处

  • 读懂敌人，而非看骰子

    战斗自动进行且零运气成分。每个敌人在开战前都展示真实装备，你的致命预警绝望之石只会在该场战斗会杀死你时才变暗。

  • 每局都有深度构筑

    选择初始加成与武器，在每位周首领后晋升两阶职业，在技能地图规划主动技能，并将10个套装系列的105件物品与零失败铁匠铺和怪物卡自由组合。

  • 过往出征会回来追猎你

    战死的猎人会在未来出征中带着旧装备复起，其中一人甚至可能以异端身份坐上地主之位。加入可选每周排行榜后，其他玩家经验证的猎人还会在巢穴作为对手等待你。

0.8 新内容

  • 猎人、怪物、地主与已穿戴装备采用 SVG 矢量美术。0.8.0 中的战斗背景、地图地砖与界面仍为像素风，战斗特效混合矢量与像素，0.9 计划将其统一为矢量美术。
  • 每周挑战与在线排行榜。所有玩家游玩相同地图布局，服务器重放每局以验证分数。你可以选择共享城市、仅共享国家或不公开地点（不登上公开榜单），其他玩家的猎人也可能在巢穴作为对手现身。
  • 离线决斗。与好友交换猎人代码，或在同一设备上让两名已保存的猎人对战。
  • 技能树新增8个按回合充能的主动技能与18个改变规则的节点，并按装备栏位细分专卖商店。
  • 匹配所选性别的猎人配音、解说出征的旁白「页边」，以及完整的巴西葡萄牙语配音。
  • 辅助功能升级，包括红盲、绿盲与蓝盲配色、每处颜色提示附带形状标记、Android 本地语音控制与实时选项图解。
