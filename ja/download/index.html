無料PC体験版をダウンロード

Windows、macOS、Linux で時間制限なく Dawnbringer を無料で試せます。初期の狩人選択肢で3週間の本編ラン全体を遊べ、家の22の恒久部屋は閉じたままになります。 バージョン 0.8.0。

体験版の内容

  • 毎回の挑戦前に性別、肌、目、髪、衣装、名前まで自由に狩人を作成可能。
  • 初期ボーナス2種、反撃と最初の血、および初期武器2種、鉄の棍棒と古い弩。
  • 一次クラス2種、ソードマンとアーチャー、および上位4種、クルセイダー、ナイト、ハンター、バード。
  • すべての地域を巡る3週間のフルラン。道中イベント、装備部位別の専門店、厳しい条件と引き換えに報酬を増やす任意の誓願、毎週の地主ボスをすべて収録。
  • 2・4・6点でセットボーナスが発動する4つの初期アイテム系統。
  • 製品版とは別のセーブデータ。残り4種のボーナス、4種の武器、4種の一次クラス、6つのアイテム系統、より大きな初期ゴールド財布を解放する家の22部屋は製品版に含まれます。

  • Windows

    Windows 10 または 11、64ビット。インストール不要で .zip を展開し DawnbringerDemo.exe を実行します。コード署名前のため Windows SmartScreen が一度警告する場合があります。詳細情報をクリックし、実行を選んでください。

    ダウンロード (360.2 MB).zip

  • macOS

    Apple silicon と Intel Mac 両対応のユニバーサルアプリ。展開して Dawnbringer をアプリケーションフォルダへドラッグしてください。

    Apple がまだアプリを公証していないため、初回起動が macOS にブロックされます。アプリを右クリックまたは Control クリックして「開く」を選んでください。「開く」がない場合はシステム設定 > プライバシーとセキュリティから「このまま開く」をクリックします。

    ダウンロード (392.6 MB).zip

  • Linux

    x86_64 アーカイブ。展開して DawnbringerDemo.x86_64 を実行してください。OpenGL 3.3 対応グラフィックドライバが必要です。

    ダウンロード (356.3 MB).tar.gz

SHA-256 チェックサムでファイルを検証

Android で遊びたいですか。テスター無料の製品版と別の無料体験版アプリの両方が Google Play クローズドテストで公開中です。 Android 参加手順を開く

iPhone と iPad 版は予定されており、現在は未配信です。
