Dawnbringer

太陽は消えた。最後の種火を運べ。

闇に沈んだ地を進み、64種の聖遺物で英雄を組み上げ、戦う相手を選べ。戦闘にダイスはなく、どの敵も読める持ち物を連れている。絶望の石は、お前を殺す戦いの前に暗くなる。週末に地主が取り立てに来たら、上納金を払うか、その首を懸けて戦え。

ゲームプレイ

体験版をダウンロード

Windows、macOS、Linux向けの無料体験版です。探索を最後まで遊べますが、選べる英雄と聖遺物は少なくなっています。 バージョン 0.4.0。

体験版の内容

  • 英雄2人：鉄鎖の悔悟者と絞首台の狙撃手。
  • 探索のすべて：マップでの3週間、イベント、ショップ、誓約、地主。
  • 最初から使える聖遺物の4系統。
  • 聖遺物箱はなし：ほかの英雄、聖遺物の系統、財布の拡張は製品版で手に入ります。
  • 製品版とは別のセーブデータ。

  • Windows

    Windows 10または11（64ビット）。.exeファイル1つで、インストールは不要です。ファイルにはまだコード署名がないため、SmartScreenの警告が出ることがあります。「詳細情報」を押し、「実行」を押してください。

    ダウンロード（163.2 MB）.exe

  • macOS

    Apple siliconとIntelのMacに対応した1つのアプリです。解凍して、Dawnbringerを「アプリケーション」へドラッグしてください。

    このアプリはまだAppleの公証を受けていないため、macOSは最初の起動をブロックします。アプリを右クリック（またはControlキーを押しながらクリック）して「開く」を選んでください。「開く」ボタンが出ない場合は、「システム設定」>「プライバシーとセキュリティ」で「このまま開く」を押してください。

    ダウンロード（116.7 MB）.zip

  • Linux

    x86_64。アーカイブを展開し、DawnbringerDemo.x86_64を実行してください。OpenGL 3.3に対応したグラフィックドライバーが必要です。

    ダウンロード（80.3 MB）.tar.gz

発売前にAndroid版を無料でテストプレイできます。

テスト決済の金額は架空です。実際に請求されることはありません。

Test card, always approvesを使うと、Google Playは購入をシミュレーションするだけです。R$9.99などの金額が表示されても、お金は引き落とされません。この支払い方法が選択されていることを確認してください。自分のカードなど実際の支払い方法が表示された場合は確定せず、ご連絡ください。

    グループを開く

  2. 2

    同じアカウントでテストページを開き、「テスターになる」を押します。参加が確認できてから次へ進んでください。

    テストページを開く

  3. 3

    AndroidのスマートフォンやタブレットでGoogle Playのゲームページを開き、「インストール」を押します。パソコンでは、表示された画面でAndroid端末を選び、Installまたは「インストール」を押します。

    Google Playからインストール

無料のベータアクセスは発売時に終了します。テストへの参加に製品版の購入は含まれません。

インストールで困ったら

グループ、テストページ、Playストアの3か所で同じアカウントを使ってください。複数のGoogleアカウントがある場合は、各ページとストアアプリのプロフィール画像を確認してください。

価格や購入ボタンが表示される場合

テスターにも価格が表示されることがあります。まず手順1と2を完了してください。パソコンではBuyまたは購入ボタンで端末選択を開きます。画像のようにInstallまたはインストールが表示されたら、Android端末を選んでそのボタンを押します。支払い画面が開いた場合は、確定前にテストカードの説明を確認してください。

Test card, always approvesとは？

Google Playのテスト用支払いカードです。支払い方法がTest card, always approvesなら、確定しても購入のシミュレーションのみで実際の請求はありません。自分のカードなど実際の支払い方法が表示される場合は確定しないでください。3つの手順のアカウントを確認し、解決しなければご連絡ください。

ゲームが表示されない、テストに参加できない場合

Playストアのアカウントでグループとテストに参加したか確認してください。数分待ってからテストページを開き直してください。解決しない場合は、支払い情報を含めずにメッセージのスクリーンショットをこちらへお送りください： dawnbringergame@gmail.com

遊び方

1回の挑戦は3週間。霧に覆われたマップを歩き、宝箱を開け、祠や鍛冶場を訪ねて、週が終わる前に聖遺物のビルドを組み上げる。戦闘はオートで進み、どの道を歩きどの装備を組むかが勝負を決める。

  • サイコロではなく、敵を読め

    戦闘は100%決定論で進む。どの敵も、挑む前に調べられる本物の持ち物を連れている。その装備を自分の装備と比べよ。絶望の石は、お前を殺す戦いになる敵に印をつけ、それ以上は何も言わない。地主に対しては沈黙したままだ。

  • 地代を払うか、戦うか

    毎週の終わりに、その地の地主が取り立てに来る。財布から上納金を払って生き延びるか、報酬を狙って戦うかを選べ。勝てばゴールドを銀行に預けて帰還することも、財布ごと次の週へ持ち越して賭けを続けることもできる。

  • 最後の夜の追跡

    週の最後の夜になると月が赤く染まり、地主がマップに現れて一歩ごとに追ってくる。ビルドが早めに完成したなら待つ必要はない。自分から玉座へ乗り込んで倒せば、報酬のゴールドが50%増える。

  • 倒れた英雄は道に残る

    英雄が死ぬと、持っていた装備のまま後の挑戦のマップに居残る。昼は道をさまよい、夜はこちらを狩りに来る。打ち倒せば、失った財布の一部を取り戻せる。

  • 勝者は新たな地主となる

    3週間を勝ち抜いた英雄は戴冠する。後の挑戦では、その英雄が地域の玉座に就き、クリア時のビルドそのままに地代を取り立てに来ることがある。

物語

教会は昼の時間を切り売りし、証文として売りさばいた。買い占めた者たちは地主となり、太陽が持つ以上の光を吸い上げた。そして「最後の朝」、太陽は地に落ちた。

マザー・ヘスパーは落日を見て視力を失いながらも、前掛けで最後の種火を受け止め、「最後の野営」の火を灯した。彼女は英雄の胸に灯芯を植え、東の「門」へと送り出す。灯芯が燃え続けるのは3週間だ。

黄金とは冷え固まった陽光であり、残された唯一のぬくもりだ。毎週、月が赤い封蝋のように空を閉じると、地主たちが地代を取り立てに来る。道半ばで倒れた者も、借りを返し終えるまで歩き続ける。

スクリーンショット

特徴

  • 固有の初期武器とパッシブを持つ6人のプレイアブル英雄。
  • 8系統・全64種の聖遺物。2、4、6個でセット効果が発動。
  • 6つの地域と3週間に待ち受ける19体の地主。
  • 巡回、伏兵、群れ、守護者、ミミックなどマップ上の敵77種。
  • 昼夜のサイクル：夜は視界が狭まり、影が迫ってくる。
  • 戦慄システム：敵を倒すほど地域の危険度と獲得ゴールドが上昇。
  • 銀行と財布の分離：出発前にゴールドを賭け、地主撃破ごとに換金できる。
  • 難度と報酬の両方を引き上げる9つの誓約。
  • 祝福17種、ベルト消耗品8種、イベント12種、鍛冶場、焚き火、泉。
  • 過去の挑戦が残響、蘇った英雄、戴冠した地主としてマップに残る。
  • 640x360ネイティブのピクセルアート。マウス、キーボード、タッチ操作に対応。
  • 14言語に翻訳済み。
