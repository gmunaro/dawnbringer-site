下載免費電腦試玩版

在 Windows、macOS 或 Linux 上無時間限制免費試玩 Dawnbringer。你可以用初始獵人選項玩完整個三週出征，宅子的22個永久升級房間保持關閉。 目前版本 0.8.0。

試玩版包含內容

  • 每次出征前完整自訂獵人，包括性別、膚色、眼睛、髮型、服裝和姓名。
  • 2個初始加成，還擊與初血，以及2件初始武器，鐵棍與舊弩。
  • 2個初階職業，劍士與弓箭手，及其4個進階職業：十字軍、騎士、獵人與詩人。
  • 涵蓋全部地區的完整三週出征，包含道路事件、依裝備欄位細分的專賣商店、以更嚴苛規則換取額外金幣的可選誓願，以及每週登場的地主首領。
  • 4個初始物品系列，穿戴2、4或6件同系列裝備即可啟動套裝加成。
  • 獨立於完整版的存檔檔案。解鎖另外4個加成、4件武器、4個初階職業、6個物品系列與更大初始金幣錢包的22個宅子房間屬於完整版。

  • Windows

    Windows 10 或 11，64位元。下載 .zip 壓縮檔解壓縮後直接執行 DawnbringerDemo.exe，無需安裝。由於檔案尚未進行程式碼簽章，Windows SmartScreen 可能會提示一次。點選「其他資訊」，再點選「仍要執行」。

    下載 (360.2 MB).zip

  • macOS

    支援 Apple silicon 與 Intel Mac 的通用應用程式。解壓縮後將 Dawnbringer 拖進「應用程式」。

    Apple 尚未對該應用程式進行公證，因此 macOS 會阻擋首次啟動。請右鍵或按住 Control 點擊應用程式並選擇「打開」。若未看到「打開」，請前往系統設定 > 隱私權與安全性，點擊「強制打開」。

    下載 (392.6 MB).zip

  • Linux

    x86_64 壓縮檔。解壓縮並執行 DawnbringerDemo.x86_64。需要支援 OpenGL 3.3 的顯示卡驅動程式。

    下載 (356.3 MB).tar.gz

透過 SHA-256 校驗碼驗證下載檔案
