Dawnbringer 的每次更新及其變動。

Dawnbringer 0.4.0

2026年10月18日 · Windows · macOS · Linux

  • 不再提供精確的戰況預測：讀取每個敵人的物品，遇到會致命的戰鬥時，你的絕望之石會變暗
  • 19種經典怪物，每隻都附帶其招式背後的物品
  • 10位NPC，各有任務、專屬音樂，對話會隨你每次相遇而改變
  • 腐屍與喪紗兩個系列、32件新物品、19個新事件
  • 可跳過的簡短教學
  • 每位英雄都有名字，也可以改名
  • 手機與大螢幕上的美術更清晰
  • 每個畫面都有回報按鈕

Dawnbringer 0.3.0

2026年10月17日 · Windows · macOS · Linux

  • 兩個新物品系列：腐屍在每場勝利後成長，喪紗讓英雄獲得虛化
  • 32件新物品：商店裡有更多裝備和更多流派
  • 19個新事件和兩條新敵人路線，減少每局的重複
  • 每個畫面都有錯誤按鈕：截圖、標記並送出回報
  • 官網提供PC版試玩

Dawnbringer 0.2.0
