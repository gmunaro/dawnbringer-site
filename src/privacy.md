# Dawnbringer — Privacy Policy

Effective date: 2026-10-15

Developer: gmunaro (individual developer) — contact: midiamunaro@gmail.com

*Versão em português abaixo.*

## Summary

Dawnbringer does not have accounts, ads, analytics, tracking or in-app purchases. Your game
progress stays on your device. The only time the game sends anything over the internet is when
you choose to send a bug report.

## Data stored on your device

The game saves your progress (profile, unlocked champions, saved builds) and your settings
(language, volume, display options) in the app's private storage on your device. This data is
not sent to us or to anyone else, and it is not included in Android cloud backups. On Android,
uninstalling the game deletes it; on PC it stays in your user data folder until you delete it. If a bug report you sent could not be delivered (for example, you were
offline), the game keeps it in the same storage and tries again the next times you open the game,
then deletes it.

## Bug reports (only when you send one)

The game has an in-game bug reporter. Nothing is sent unless you open it and press Send. A report
contains:

- the description you type;
- a screenshot of the game screen, unless you untick "Attach this screenshot" before sending;
- the game version, the operating system name and version, and the game's language setting;
- where you were in the game: the current screen and, during a run, the champion, week, day and
  the run's seed (the number that generates the run's map);
- an excerpt of the game's own log (technical messages from the game, such as errors). The game
  removes the path of its data folder from the excerpt; other file paths, such as the folder the
  game is installed in, may still appear. On Android the game keeps no log file, so no excerpt is
  sent.

The report is sent over an encrypted connection (HTTPS) to a server run by the developer on
Cloudflare Workers (Cloudflare, Inc.), which files it as an issue in a private GitHub repository
and stores the screenshot in the same repository (GitHub, Inc. hosts it as our service provider).
We use reports only to find and fix bugs. We do not sell them, share them with third parties for
their own use, or use them for advertising.

Like any internet connection, the server sees your IP address while receiving the report. To stop
abuse, it keeps a count of reports per IP address (for IPv6, per network prefix) for up to two
hours, then the count is deleted automatically. The server also keeps technical logs of each
request (Cloudflare Workers Logs), which may include your IP address, for a few days (at most 7)
before they are deleted automatically; the developer can read them to fix problems with the
server. The IP address is not added to the report.

Please do not type personal information (such as your name, email or phone number) in the
description. Reports are kept while the bug is being worked on and then may be kept as part of
the project's issue history. To have a report deleted, email midiamunaro@gmail.com with the
date you sent it and a few words of its description, and we will delete it.

## Children

Dawnbringer is not directed at children under 13, and we do not knowingly collect personal
information from children.

## Changes

If this policy changes, the new version will be posted at this address with a new effective
date.

# Dawnbringer — Política de Privacidade

Data de vigência: 2026-10-15

Desenvolvedor: gmunaro (desenvolvedor individual) — contato: midiamunaro@gmail.com

## Resumo

Dawnbringer não tem contas, anúncios, analytics, rastreamento nem compras no app. Seu progresso
fica no seu aparelho. O jogo só envia algo pela internet quando você decide mandar um relatório
de bug.

## Dados guardados no seu aparelho

O jogo salva seu progresso (perfil, campeões desbloqueados, builds salvas) e suas configurações
(idioma, volume, opções de tela) no armazenamento privado do app no seu aparelho. Esses dados não
são enviados para nós nem para ninguém e não entram no backup em nuvem do Android. No Android,
desinstalar o jogo apaga esses dados; no PC eles ficam na sua pasta de dados de usuário até você
apagá-la. Se um relatório de bug que você enviou não puder ser entregue (por exemplo,
sem internet), o jogo o guarda nesse mesmo armazenamento e tenta de novo nas próximas vezes que
você abrir o jogo; depois o apaga.

## Relatórios de bug (só quando você envia)

O jogo tem um relator de bugs. Nada é enviado a menos que você o abra e toque em Enviar. Um
relatório contém:

- a descrição que você digitar;
- uma captura da tela do jogo, a menos que você desmarque "Anexar esta captura de tela" antes de
  enviar;
- a versão do jogo, o nome e a versão do sistema operacional e o idioma configurado no jogo;
- onde você estava no jogo: a tela atual e, durante uma partida, o campeão, a semana, o dia e a
  semente da partida (o número que gera o mapa da partida);
- um trecho do log do próprio jogo (mensagens técnicas do jogo, como erros). O jogo tira do trecho
  o caminho da sua pasta de dados; outros caminhos de arquivo, como a pasta onde o jogo está
  instalado, ainda podem aparecer. No Android o jogo não grava arquivo de log, então nenhum
  trecho é enviado.

O relatório vai por conexão criptografada (HTTPS) para um servidor do desenvolvedor no Cloudflare
Workers (Cloudflare, Inc.), que o registra como uma issue num repositório privado no GitHub e
guarda a captura de tela nesse mesmo repositório (o GitHub, Inc. hospeda como nosso prestador de
serviço). Usamos os relatórios só para achar e corrigir bugs. Não vendemos, não compartilhamos com
terceiros para uso próprio deles e não usamos para publicidade.

Como em qualquer conexão à internet, o servidor vê seu endereço IP ao receber o relatório. Para
evitar abuso, ele guarda uma contagem de relatórios por endereço IP (no IPv6, por prefixo de rede)
por até duas horas, e depois a contagem é apagada automaticamente. O servidor também guarda
registros técnicos de cada requisição (Cloudflare Workers Logs), que podem incluir seu endereço IP,
por alguns dias (no máximo 7), e depois eles são apagados automaticamente; o desenvolvedor pode
lê-los para corrigir problemas do servidor. O endereço IP não entra no relatório.

Não escreva dados pessoais (nome, e-mail, telefone) na descrição. Os relatórios ficam guardados
enquanto o bug é tratado e podem continuar no histórico de issues do projeto. Para apagar um
relatório, mande um e-mail para midiamunaro@gmail.com com a data do envio e algumas palavras da
descrição, e nós o apagaremos.

## Crianças

Dawnbringer não é direcionado a menores de 13 anos, e não coletamos dados pessoais de crianças
de propósito.

## Mudanças

Se esta política mudar, a nova versão será publicada neste mesmo endereço com nova data de
vigência.
