Download the free desktop demo

Try Dawnbringer free on Windows, macOS, or Linux, with no time limit. You play the full three-week run with a starter selection of hunter options, while the 22 permanent upgrade rooms of your House stay closed. Version 0.8.0.

What is included in the demo

  • Full hunter customization before each run, including sex, skin, eyes, hair, outfit, and name.
  • 2 starting bonuses, Riposte and First Blood, and 2 starting weapons, Iron Club and Old Crossbow.
  • 2 first classes, Swordsman and Archer, and their 4 second classes: Crusader, Knight, Hunter, and Bard.
  • The complete three-week run across all regions, with road events, slot-specific shops, optional Vows that trade harder rules for extra gold, and weekly Landlord bosses.
  • The 4 starting item families, themed gear groups that unlock set bonuses at 2, 4, or 6 pieces.
  • A separate save file from the full game. The 22 permanent rooms of the House, which unlock 4 more bonuses, 4 weapons, 4 first classes, 6 item families, and larger starting gold purses, are in the full game.

  • Windows

    Windows 10 or 11, 64-bit. Download the .zip archive, extract it, and run DawnbringerDemo.exe with no installer. Because the file is not code-signed yet, Windows SmartScreen may warn you once. Click More info, then Run anyway.

    Download (360.2 MB).zip

  • macOS

    Universal app for Apple silicon and Intel Macs. Unzip the file and drag Dawnbringer into Applications.

    Apple has not notarized the app yet, so macOS blocks the first launch. Right-click or Control-click the app and choose Open. If Open does not appear, go to System Settings > Privacy & Security and click Open Anyway.

    Download (392.6 MB).zip

  • Linux

    x86_64 archive. Extract it and run DawnbringerDemo.x86_64. Requires graphics drivers supporting OpenGL 3.3.
